# SyHost

[English](README.md) · [Türkçe](README.tr.md) · **日本語**

**MOD入り Minecraft サーバーをワンクリックでセットアップ・起動・管理。**
Modrinth パック（`.mrpack`）を選ぶだけで、Java・MOD ローダー・MOD・設定を SyHost が自動でインストールします。
友達はインターネット経由で参加でき、あなたはアニメーション付きのかっこいいターミナル画面からすべてを操作できます。

> Windows 10 / 11 · NeoForge · Forge · Fabric · English, Türkçe, 日本語 · 作者: **sykait**

---

## ✨ 機能

- **ワンクリックでサーバーをインストール** – `.mrpack` を選ぶだけ
  （適切な Java、NeoForge/Forge/Fabric、サーバー用 MOD、設定ファイル、パックのワールド）。
- **複数サーバー** – 一覧から選んで Enter。
- **友達用の接続** – [playit.gg](https://playit.gg) で無料の固定アドレス
  （多くの家庭用回線の CGNAT を回避）。playit は SyHost が開いている間だけ動きます。
- **リアルタイム状態表示** – 起動中 / 稼働中 / 停止中のバー、プレイヤー、RAM・CPU 使用率。
- **シンプルコンソール** – 重要な出来事だけ表示（参加・退出・チャット・エラー）。全ログはキー1つで。
- **パフォーマンスパック** – 低 / 標準 / 高。PC の RAM とコア数に合わせて自動調整。
- **自動バックアップ** – 3時間ごと、最新10個を保存。
- **安全な終了** – F10 → ワールドを保存し、サーバーを停止。何も残りません。
- **ミニモード** – 画面の隅に置ける小さな状態ウィンドウ（Ctrl+Alt+K）。
- **非表示 / 表示** – ゲーム中でも Ctrl+Alt+G で。
- **3言語対応** – English・Türkçe・日本語（メインメニューで **L** キー）。

## 📥 インストール

### 方法1 — 1行で（いちばん簡単）

スタートメニューから **PowerShell** を開き、次の1行を貼り付けて Enter:

```powershell
irm https://raw.githubusercontent.com/sykait/SyHost/main/install.ps1 | iex
```

SyHost をダウンロードしてセットアップを開始します。同じコマンドで**アップデート**もできます
（サーバーと設定はそのまま残ります）。

### 方法2 — zip で

1. このページの緑の **Code** ボタン → **Download ZIP**。
2. 任意のフォルダに展開（例: `ドキュメント\SyHost`）。
3. **`Setup.bat`** をダブルクリック。
   - 「Windows によって PC が保護されました」と出たら: **詳細情報 → 実行**。

### セットアップの内容

| ステップ | 内容 |
|---|---|
| 0 | 言語を選択（English / Türkçe / 日本語） |
| 1 | Windows と winget を確認 |
| 2 | Java 21 がなければインストール |
| 3 | 必要なら playit.gg をインストールし、ブラウザでアカウントと連携 |
| 4 | Cascadia Mono フォントをインストール（アニメーションを正しく表示するため） |
| 5 | デスクトップとスタートメニューに **SyHost** のショートカットを追加 |

Windows が1〜2回許可を求めることがあります。「はい」を選んでください。

## 🎮 最初のサーバー

1. **SyHost** を開く。
2. **新しいサーバーを追加** を選ぶ（または `+` キー）。
3. [Modrinth](https://modrinth.com/modpacks) からダウンロードした `.mrpack` を選ぶ。
4. 名前を付ける →（パックにワールドがあれば）ワールドを選ぶ → **Enter** でインストール。
5. 完了したら **Enter** → サーバーが起動。上部のバーが **サーバー稼働中** になれば準備完了です。

## 👥 友達を招待する

1. サーバー画面で `copy` と入力して Enter → アドレスがコピーされます。
2. Discord で友達に貼り付け。
3. 友達は同じ MOD パック（同じバージョン！）を Modrinth App か Prism Launcher で開き →
   **マルチプレイ → サーバーを追加** → アドレスを貼り付け。

## ⌨️ ショートカット

| キー | 動作 |
|---|---|
| **F1** | ヘルプ |
| **F2** | 非表示 – サーバーは動き続けます |
| **F3** | パフォーマンスパックを選択 |
| **F4** | ミニ / 通常モード |
| **F5** | シンプル / 詳細コンソール |
| **F6** | ミニモードを最前面に固定 |
| **F10** | 閉じる（ワールドは保存されます） |
| **L** | 言語を変更（メインメニュー） |
| **Ctrl+Alt+K** | ミニ / 通常モード – どこからでも、ゲーム中でも |
| **Ctrl+Alt+G** | 非表示 / 表示 – どこからでも |

## 💬 コマンド

| コマンド | 動作 |
|---|---|
| `start` / `stop` / `restart` | サーバーの起動 / 停止 / 再起動 |
| `pack normal` | パフォーマンスパックの変更（`low`・`normal`・`high`） |
| `backup` | ワールドをバックアップ |
| `players` | オンラインのプレイヤー |
| `copy` | 友達用アドレスをコピー |
| `folder` | サーバーフォルダを開く |
| `menu` / `exit` | メインメニューへ / SyHost を終了 |

それ以外の入力はそのまま Minecraft に送られます: `op 名前`、`kick 名前`、`say こんにちは`、`time set day`…

## ❓ よくある質問

**playit は必須？**
いいえ。セットアップで「いいえ」を選ぶと、このPC（`localhost`）と同じ家のネットワークから参加できます。
友達がインターネット経由で参加し、回線が CGNAT の場合は playit が必要です。

**PC は重くなる？**
SyHost 自体はとても軽量です。サーバーが使う RAM とコア数はパック（F3）で選べます。

**設定やサーバーはどこ？**
- 設定とサーバー一覧: `%LOCALAPPDATA%\SyHost`（プログラムフォルダの中ではありません）
- サーバー: 既定は `%USERPROFILE%\SyHost Sunuculari`
- バックアップ: 各サーバーの `yedekler` フォルダ

**Mac / Linux は？**
現在は Windows 10 / 11 のみです。
