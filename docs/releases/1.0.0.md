## Which file should I download?

| File | Who it's for |
|---|---|
| **SyHost-1.0.0.exe** | **Everyone.** The main edition, written in C#. One file, nothing to install, opens instantly. |
| SyHost-1.0.0-Terminal.exe | The PowerShell edition (the app as it was in 0.5.0, improved). Same screens, same data; pick it only if you prefer it. |

Both editions look exactly the same and use the same settings, so you can switch by replacing the exe.
`SHA256SUMS.txt` lists the checksums of both files.

### First start

1. Download **SyHost-1.0.0.exe** and double-click it.
2. Windows may show "Windows protected your PC" because the file is new and not signed. Click **More info → Run anyway**.
3. Pick your language and where SyHost should live (default: `C:\Users\<you>\SyHost`). SyHost moves itself there and walks you through Java, the connection for your friends, the font and the shortcuts.

If you used SyHost 0.5.0, your settings, server list and playit connection are copied over automatically. Your servers stay where they are.

## What's new in 1.0

- **One file.** The whole app is a single `SyHost.exe`. No setup, no readme, no batch files.
- **Everything in one folder.** Settings, servers, Java and playit live next to `SyHost.exe`. Move the folder anywhere (another drive, a USB stick) and it keeps working.
- **Settings screen** (F9): language, server folder, shortcuts, friend connection, Java, backups and more.
- **Uninstall from inside SyHost**: removes the shortcuts and everything SyHost put outside its folder, step by step; it can delete the folder too.
- **Nothing installed system-wide.** Java is downloaded into the SyHost folder only when your PC doesn't have it, playit runs from the folder only while SyHost is open, and the font is installed for your user without admin rights.
- **Faster, sturdier server installs.** Mods download in parallel and every file is verified against the pack's checksums.
- **New icon** in the window, the taskbar, the tray, the shortcuts and Explorer; folders show their names in your language.
- **Fixes:** some English and Japanese labels showed the wrong text (for example the "NEW SERVER" card title); the tray menu is now translated.
