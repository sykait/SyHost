## Which file should I download?

| File | Who it's for |
|---|---|
| **SyHost-1.0.0.exe** | **Everyone (recommended).** The main edition, written in C#. |
| SyHost-Terminal-1.0.0.exe | The same app as a PowerShell edition, for people who like to read the scripts. |

Both editions look the same on screen (only the version line says `C#` or `Terminal`) and keep the same files in the
same folder, so you can switch later. Each one is a single file with nothing else to download.
The SHA-256 checksums of both files are at the end of these notes.

### First start

1. Download **SyHost-1.0.0.exe** and double-click it.
2. Windows may show "Windows protected your PC" because the file is new and not signed. Click **More info → Run anyway**.
3. Pick your language and where SyHost should live (recommended: `C:\Users\<you>\SyHost`). SyHost copies itself
   there, opens again from there and walks you through Java, the connection for your friends, the font and the shortcuts.

Used SyHost 0.5.0? The first time the new SyHost starts, it copies your settings, server list and playit connection
into its own folder. Your servers stay where they are, new servers go into the SyHost folder (unless you had picked
your own server folder in 0.5.0; that choice is kept), and the old folder is not deleted.

To update later, download the new exe, open it and choose your SyHost folder: SyHost is replaced there and your
servers, worlds and settings are kept.

## What's new in 1.0

- **One file.** The app is a single exe you download and open: no setup program, no batch files.
- **Everything in one folder.** Settings, servers, the downloaded Java and playit live next to `SyHost.exe`. Move the
  folder and open `SyHost.exe` from its new place: it repairs its Desktop and Start-menu shortcuts.
- **First start inside the app:** language, folder, Java, the connection for your friends, the font and the shortcuts,
  step by step.
- **Settings screen** (F9 in the main menu): language, server folder, shortcuts, text size, friend connection, Java,
  max players, automatic backups, restart after a crash.
- **Uninstall from inside SyHost:** it lists everything SyHost left outside its folder and you choose what goes.
  It can empty its own folder too (then you delete the rest in Explorer). Java is never selected by default.
- **Plain and checkable.** No hidden PowerShell or cmd windows, no encoded commands, no code built from text while
  it runs, no self-deleting helper, nothing that starts with Windows. A downloaded playit is kept only if it matches
  the SHA-256 GitHub lists for it and Windows finds its signature valid. Mods are checked against the checksums in the
  pack, and Java against Adoptium's.
- **Nothing installed system-wide.** Java is downloaded into the SyHost folder only when your PC doesn't have the right
  version, playit runs from the folder only while SyHost is open, and the font is installed for your user without
  admin rights.
- **Sturdier server installs.** Every mod is downloaded to a temporary file and only kept when its checksums match
  (packs that list only SHA-512 work too), the pack's server-overrides win over its overrides, and both editions
  download six mods at a time.
- **Minecraft 26.x** packs get Java 25.
- **New servers get SyHost's icon** in Minecraft's server list when the pack doesn't bring its own.
- **New icon** in the window, the taskbar, the tray, the shortcuts and Explorer. In Explorer the folders also show their
  names in your language.
- **Fixes:** some English and Japanese labels could show the text of another, similar label (for example the
  "NEW SERVER" card title); the tray menu is now translated; `force` closes only servers that SyHost started (a
  Minecraft server another program started is left alone, and SyHost says so).
